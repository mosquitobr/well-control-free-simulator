3. BUNDLED JAVA RUNTIME IN DESKTOP INSTALLERS (Windows MSI/ZIP & Linux DEB/TAR)
--------------------------------------------------------------------------------

The standalone Desktop installers (.msi, .deb, portable .zip, portable .tar.gz)
built with jpackage/jlink bundle a minimal unmodified Eclipse Temurin OpenJDK 21
runtime image (modules: java.desktop, java.logging, java.xml, jdk.unsupported).

- Eclipse Temurin (OpenJDK 21)
  License: GNU General Public License, version 2, with the Classpath Exception
           (GPL-2.0-with-classpath-exception)
  License text & component notices: Preserved inside the runtime/legal/ folder
  of every packaged desktop distribution.
  Upstream source code: https://adoptium.net/ / https://github.com/adoptium/temurin21-binaries

Under the Classpath Exception, combining the Apache-2.0 application with the
unmodified OpenJDK runtime does not place the application code under the GPL.
The Uber JAR distribution does not bundle OpenJDK.
